# Word Guessing Game

Guess the hidden word one letter at a time before you run out of attempts.

## How to run

```bash
python3 word_guessing.py
```

Python 3 only — no extra packages needed.

## How to play

- A word is picked at random and shown as blanks (`_`).
- Guess one letter at a time.
- A correct letter is revealed in the word; a wrong letter costs one attempt.
- You have 6 attempts per word — guess the whole word before they run out.
- Your score (words won and lost) is shown after every round.
- Type `n` when asked to play again to quit.
